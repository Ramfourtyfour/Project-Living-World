# Licensing and provenance policy

The implementation in this repository is original work prepared for Project Living
World. No Shattered PD code, media, names for copied items, or other protected game
assets are included. The scene is generated from mathematical primitives and the
viewer uses system fonts. There are no downloaded art/audio assets.

No open-source distribution license has been chosen for the project. `LICENSE`
reserves rights until the owner selects one; publishing source alone does not
establish a permissive grant. No third-party engine/library source is vendored.

The C++ core uses the standard library. Windows builds use the MSYS2 GCC runtime
under its applicable runtime exception. A release distribution requires a full
runtime/notice audit; this prototype is not the audited release candidate.
Python, Tk/Tcl, pytest, NumPy, PyTorch and GitHub Actions are external tools with
their own licenses. They are not relicensed here. Experimental model weights are
trained locally from synthetic simulation trajectories, not downloaded checkpoints.

The user-supplied master plan is retained as project design reference. Its presence
is not authorization to upload unrelated files, spend money, contact people or
perform other external actions.
