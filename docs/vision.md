# Product vision

Live as one person in an original fantasy wilderness. Independent inhabitants
gather, explore, negotiate, migrate and eventually construct communities using the
same world rules as human players. Individuals know what they perceive and remember;
sharing policy weights never shares personal memories or creates a faction mind.

The intended product is a first-person co-op survival RPG. The present artifact is
the headless foundation. A desktop diagnostic viewer makes state and causality
inspectable while the scientific assumptions are tested.

Evidence is part of the product: no claim of learned society without held-out
behavioral measurements. Resource creation must have recorded causes; transactions
must preserve ownership and identities across restart. Social changes arise from
individual requests rather than forced trust thresholds.

The full design reference is `master-plan.md`. Implementation status is tracked in
`milestones.md`. Unsupported features remain explicitly unsupported.
