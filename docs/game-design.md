# Prototype game rules

The 240 m test region has four starting camps, nearby food/water/material nodes,
additional scattered resources and four impassable stone formations. Sixteen to
thirty-two inhabitants are the primary target; sixty-four is a stress configuration.
Everything is generated once from a world seed. Starting agents own no supplies.

An individual's three needs increase each tick. Food/water consumption and rest
reduce the relevant need. Extreme unmet needs cause injury, then permanent death
in this prototype. Inventory persists on deceased identities. Revival and player
recovery rules are planned but unavailable. The viewer can reset to a new seed.

Each human or policy intent becomes the same native action request. Movement,
range and visibility are checked. An agent may gather a visible reachable node,
but cannot ask the registry where unseen resources are. Old sightings are beliefs.
Gifts and barter require voluntary acceptance, current access and real stock.
Membership can be left without another actor's approval.

This region has no terrain biomes, weather, seasons, sound, enemies, equipment,
building, crafting, storage, new population or rebirth. Those belong to later gates.
The native renderer will ultimately be replaceable independently of these rules.
